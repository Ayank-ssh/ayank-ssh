AYANK PROFILE — V10

The contribution section is now a proper compact GitHub-style calendar:
- 7 weekday rows
- 5–6 week columns depending on the month boundary
- larger square cells with rounded corners
- month labels
- contribution intensity from dark -> crimson -> red
- hover tooltips for exact date + count
- compact header and legend
- no giant title or stretched 6x5 card

It automatically refreshes through the existing Sync Contribution Graph workflow.

Install:
  git add .
  git commit -m "Redesign contribution graph"
  git push

Then run the workflow once from:
  Actions -> Sync Contribution Graph -> Run workflow
